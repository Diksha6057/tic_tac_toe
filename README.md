# 🎮 Tic Tac Toe

A browser-based implementation of the classic Tic Tac Toe game, built using **HTML5, CSS3, and Vanilla JavaScript**. This project features interactive two-player gameplay, dynamic game-state management, and automatic win/draw detection through a clean, responsive interface.

## ✨ Features

- **🎯 Turn-Based Gameplay** — Alternating moves between two players (X and O).
- **🏆 Win Detection** — Identifies winning combinations across rows, columns, and diagonals.
- **🤝 Draw Detection** — Recognizes when the board is full without a winning combination.
- **⚡ Dynamic Game State** — Updates the board and game status based on player interactions.
- **📱 Responsive Interface** — Adapts to different screen sizes.
- **🌐 Browser-Based Execution** — Runs directly in a modern browser without additional dependencies.

## 🛠️ Technology Stack

| Technology | Implementation |
|---|---|
| HTML5 | Semantic structure |

## 🚀 Getting Started

Follow these instructions to run the project locally.

### 📋 Prerequisites

- A modern web browser.
- Git installed on your system.

### 💻 Installation

**1. Clone the repository**

```bash
git clone https://github.com/Diksha6057/tic_tac_toe.git
```

**2. Navigate to the project directory**

```bash
cd tic_tac_toe
```

**3. Launch the application**

Open `index.html` in your preferred web browser.

No additional packages, dependencies, or build tools are required.

## 🎮 Game Rules

1. The game is played between two players: X and O.
2. Players alternate turns by selecting an empty cell.
3. The first player to align three marks horizontally, vertically, or diagonally wins.
4. If all nine cells are occupied without a winner, the game ends in a draw.
