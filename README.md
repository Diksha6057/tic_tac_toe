Tic Tac Toe Game

A simple and interactive Tic Tac Toe game built using **HTML, CSS, and JavaScript**.  
This project allows two players to play turn-by-turn in a browser with automatic win and draw detection.

  Features
- 2-player gameplay (X and O)
- Automatic win detection
- Draw condition handling
- Simple and clean UI
- Responsive design

 Technologies Used
- HTML
- CSS
- JavaScript
