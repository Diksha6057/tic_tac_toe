# Tic Tac Toe

A browser-based implementation of the classic Tic Tac Toe game, developed using **HTML5, CSS3, and Vanilla JavaScript**. The application provides an interactive two-player experience with automated game-state management and win/draw detection.

## Overview

Tic Tac Toe is a two-player strategy game played on a 3 × 3 grid. Players alternate between X and O, aiming to align three marks horizontally, vertically, or diagonally.

This project implements the complete game logic in JavaScript and presents it through a responsive browser interface.

## Features

- **Turn-Based Gameplay** — Alternating moves between two players (X and O).
- **Winning Condition Detection** — Identifies winning combinations across rows, columns, and diagonals.
- **Draw Detection** — Determines when all cells are occupied without a winning combination.
- **Dynamic Game State** — Updates the board and game status based on player interactions.
- **Responsive Interface** — Adapts the layout to different screen sizes.
- **Browser-Based Execution** — Runs directly in a modern web browser without additional dependencies.

## Technology Stack

## Getting Started

Follow these instructions to run the project locally.

### Prerequisites

- A modern web browser.
- Git installed on your system.

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Diksha6057/tic_tac_toe.git
```

**2. Navigate to the project directory**

```bash
cd tic_tac_toe
```

**3. Run the application**

Open `index.html` in your preferred browser.

No additional packages or build tools are required.

## Game Rules

1. The game is played between two players: X and O.
2. Players take turns selecting an empty cell.
3. The first player to align three marks horizontally, vertically, or diagonally wins.
4. If all nine cells are occupied without a winning combination, the game ends in a draw.
